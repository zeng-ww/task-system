# Team Task System

## 项目简介

团队开发协作任务系统，支持用户注册登录、项目管理、任务创建、任务指派、任务状态流转和任务筛选。

## 技术栈

- 后端：Java 17、Spring Boot 3.3.5
- 数据库：MySQL
- 持久层：MyBatis
- 接口测试：Apifox
- 版本管理：Git + GitHub

## 功能模块

### 用户模块

- 用户注册
- 用户登录
- 获取用户信息
- 密码加密存储

### 项目模块

- 创建项目
- 查看项目列表

### 任务模块

- 创建任务
- 查询任务列表
- 按状态筛选任务
- 按优先级筛选任务
- 修改任务状态：TODO → DOING → DONE
- 指派任务给已注册用户
